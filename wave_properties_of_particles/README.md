# Wave–Particle Lab 2027

ชุดปฏิบัติการออนไลน์เสมือนจริงเรื่องสมบัติความเป็นคลื่นของอนุภาค (3 บท)

## วิธีเปิด

```bash
cd modernphysics2027/wave_properties_of_particles
python3 -m http.server 8002
```

เปิด http://localhost:8002 ผ่านเว็บเบราว์เซอร์สมัยใหม่ ขณะออนไลน์ (ใช้ Three.js 0.160.1 ผ่าน jsDelivr CDN)

## เนื้อหา

1. de Broglie: λ=h/p และโมเมนตัมจากพลังงานจลน์เชิงสัมพัทธภาพ; เลือก electron / proton / neutron.
2. Davisson–Germer: อิเล็กตรอนชนผลึกนิกเกิล; กฎของแบรกก์ nλ=2d sin θ; แบบจำลองความเข้มอย่างง่ายและจุดวัดที่ปรับมุมได้.
3. Gaussian wave packet: ΔxΔp=ℏ/2; อิทธิพลของความกว้างกลุ่มคลื่นและความยาวคลื่นพาหะ.

ปุ่มหยุด/เล่นฉาก, คืนค่าเริ่มต้น, ส่งออก CSV (ตัวเลขกราฟ 361 จุด), หมุนและซูมกล้องสามมิติ.

## ขอบเขตและสมมติฐาน

- ลำอิเล็กตรอนเดวิสสัน–เจอร์เมอร์คำนวณ λ จากโมเมนตัมเชิงสัมพัทธภาพ แต่กราฟความเข้มเป็น Gaussian peak เชิงปรากฏการณ์ ไม่ได้รวม dynamical diffraction, background apparatus, multiple scattering หรือ lattice orientation ครบถ้วน.
- ระนาบผลึก Ni และความสัมพันธ์ระหว่างมุมกระเจิงกับมุมแบรกก์ใช้เรขาคณิตการสอน φ = 180° − 2θᴮ ไม่ครอบคลุมเรขาคณิตทั้งหมดของเครื่องทดลองต้นฉบับ.
- กลุ่มคลื่นเป็น Gaussian ที่เวลาหนึ่ง; การเปลี่ยนเฟสและการแกว่งในฉากเป็นการแสดงผลเชิงภาพ ไม่รวมการแผ่กว้างตามเวลาของกลุ่มคลื่นในอวกาศจริง.
- ค่าฟิสิกส์แสดง SI; ตัววัตถุและการเคลื่อนไหวใน 3D ไม่ใช่มาตราส่วนจริง.
- ใช้เพื่อการเรียนรู้ ไม่ใช่เครื่องมือวิเคราะห์ข้อมูลเครื่องทดลองห้องปฏิบัติการจริง.
