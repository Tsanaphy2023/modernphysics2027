ต้องมีเว็บเบราว์เซอร์สมัยใหม่และการเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด Three.js (CDN)

```bash
python3 -m http.server 8000
```

เปิด `http://localhost:8000` ในเบราว์เซอร์ รองรับ Chrome, Edge, Firefox และ Safari รุ่นใหม่

## ความสามารถ

1. **สมมติฐานของไอน์สไตน์** — การเคลื่อนที่ของนาฬิกาแสงและค่าคงตัว c
2. **กาลิเลียนและลอเรนตซ์** — คำนวณพิกัด (x',t') ของเหตุการณ์ในกรอบอ้างอิงสองแบบ
3. **การยืดเวลาและหดความยาว** — นาฬิกาแสง, γ, L=L₀/γ
4. **ดอปเพลอร์สัมพัทธภาพ** — ความถี่, ความยาวคลื่น, blueshift/redshift ตามแนวเล็ง
5. **โมเมนตัมและพลังงานสัมพัทธภาพ** — p, E, K เทียบกับแบบนิวตัน
6. **ความสมมูลมวลและพลังงาน** — ΔE=Δmc² และหน่วย SI

ปรับ β = −0.95…0.95; เลือกความเร็วสำเร็จรูป; เล่น/หยุด/เริ่มใหม่; เปลี่ยน time scale; หมุน/ซูมฉาก Three.js; แสดงผลกราฟ Canvas และส่งออก CSV

## ข้อกำหนดเชิงวิทยาศาสตร์และขอบเขต

- ใช้ **c = 299,792,458 m/s** (ค่าคงที่ SI), β=v/c และ γ=1/sqrt(1−β²)
- การแปลงลอเรนตซ์: x′=γ(x−vt), t′=γ(t−vx/c²)
- ในโมดูลการแปลงพิกัด ใช้ `x` หน่วย light-second และ `t` หน่วย second ดังนั้น x′=γ(x−βt), t′=γ(t−βx)
- เวลาแท้ Δτ วัดในกรอบพักของนาฬิกา การหดความยาวใช้การวัดปลายทั้งสองพร้อมกันในกรอบผู้สังเกต
- ดอปเพลอร์ใช้สูตรการเคลื่อนที่ตามแนวเส้นตรง: f_obs=f₀ √((1+β)/(1−β)), β>0 หมายถึงเข้าใกล้
- มวล m คือ **มวลนิ่ง** ไม่ใช้แนวคิดมวลเพิ่มตามความเร็ว
- โมเดลภาพสามมิติเป็นภาพสาธิตที่ **ไม่ได้ใช้สเกลเดียวกับระยะทางทางฟิสิกส์จริง**; ตัวเลขและกราฟคำนวณจากสมการสัมพัทธภาพ ส่วนวงคลื่น/อนุภาคเป็นสัญลักษณ์เชิงทัศนภาพ
- การแสดงผลไม่รวมแรงโน้มถ่วง ความเร่ง การมองเห็นเชิงแสงแบบ Terrell rotation หรือการจำลองสนามแม่เหล็กไฟฟ้าเต็มรูปแบบ
