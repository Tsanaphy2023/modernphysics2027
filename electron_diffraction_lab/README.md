## โมดูลการทดลองทั้ง 5 ส่วน

1. **หลอดเลี้ยวเบนอิเล็กตรอน (`teltron`)** — จำลองหลอดสุญญากาศ Teltron, ปืนอิเล็กตรอน, เป้าฟิล์มแกรไฟต์หลายผลึก และฉากเรืองแสงสีเขียวแสดงวงแหวนเลี้ยวเบน $R_1, R_2$ พร้อมเวอร์เนียร์วัดขนาดแบบเรียลไทม์
2. **คลื่นสสารเดอบรอยล์ (`debroglie`)** — แสดงคลื่นสสาร 3 มิติ $\psi(x, t)$ เปรียบเทียบความยาวคลื่น $\lambda$ ระหว่างอิเล็กตรอน ($e^-$), มิวออน ($\mu^-$) และโปรตอน ($p^+$)
3. **ผลึกแกรไฟต์และกฎของแบรกก์ (`crystal`)** — แบบจำลอง 3 มิติของผลึกแกรไฟต์และระนาบอะตอม $(10)$ ($d_{10} = 0.213\text{ nm}$) กับ $(11)$ ($d_{11} = 0.123\text{ nm}$) ตามกฎ $2d\sin\theta = n\lambda$
4. **ช่องแคบคู่ทีละอิเล็กตรอน (`doubleslit`)** — ยิงอิเล็กตรอนทีละตัวสะสมบนฉากพร้อมสวิตช์เปิด–ปิดเครื่องตรวจวัดเส้นทาง (Which-Way Detector) เพื่อสังเกตการหายไปของแถบแทรกสอด
5. **บันทึกผลและประเมินนักศึกษา (`assessment`)** — ตารางบันทึกผลการทดลอง $(V_a, V_a^{-1/2}, \lambda, R_1, R_2)$, กราฟถดถอยเชิงเส้นหา $d_{10,\text{exp}}, d_{11,\text{exp}}$, คำนวณ `% Error`, ส่งออกไฟล์ CSV และแบบทดสอบประเมินความเข้าใจ 5 ข้อพร้อมเฉลยอธิบาย
